# 未决与关闭条件

| ID | 缺口 | 关闭证据 |
|---|---|---|
| OPEN-DBG-01 | 各层真实失败样本、成功对照、30分钟定位目标实测 | T01–T07至少对应场景的真实运行记录及证据；合成D案例不替代 |
| OPEN-DBG-02 | 当前主机无tshark/dumpcap；BPF/显示过滤未在目标工具编译/选帧 | 固定工具版本与链路类型的编译结果、正常/排除帧号；本地字符串测试不足 |
| OPEN-DBG-03 | 目标车机RTSP扩展状态、内部错误与响应的完整映射 | 同次请求/响应+对应实现或日志；不得从通用RFC表推断 |
| OPEN-DBG-04 | 完整控制/配对超时、重试/恢复幂等性 | 对应profile源实现或受控重复/超时实验，含资源/nonce状态 |
| OPEN-DBG-05 | 完整认证信任、目标provider与媒体互通闭环 | 合法信任材料、握手/协商/认证/解码/呈现运行证据；不能靠改配置跳过 |
| OPEN-DBG-06 | 跨车机/固件/平台兼容矩阵 | 第二个真实组合与单变量比较；23G90与24A446不同来源不算对照运行 |
| OPEN-DBG-07 | 原始抓包/第三方日志的隐私审核流程尚无真实包验收 | 获授权原始包的本地审查及脱敏分享包；safe_event只覆盖自己的结构化日志 |

没有真实样本时仍可继续静态错误路径和可执行夹具，不因上述OPEN停止所有文档工作。
任务范围仍包含视频、音频/麦克风、输入生命周期，不将排障章节存在当作四组目标完成。
