# 日志与隐私

本地策略：记录边界、结果和计数，不记录可重建用户内容或认证秘密的数据。
结构化日志和原始取证包分开；原始包只在获授权、受控存储中短期保留，分享前单独审查。

## 必需观测点

| 位置 | 推荐记录 | 不可等同 |
|---|---|---|
| 业务请求入队/写socket/写完成 | 本地操作号、字节数、排队时长、剩余字节 | 写完成≠对端收到 |
| 接收/重组/校验 | 读取字节数、帧长、profile校验宽度、失败域 | 收到≠校验通过 |
| 认证/识别/特性门 | 当前epoch、阶段、通过/拒绝、理由枚举 | 识别通过≠认证通过 |
| 密码边界 | provider类别、方向、材料代际编号、长度、认证结果 | 返回0≠该路径一定执行了认证 |
| 媒体提交/解码/呈现 | 流号、累计帧数、队列深度、丢弃理由、时钟域 | 包解析通过≠有声/有画面 |
| 输入报告/应用消费 | 匿名组件编号、描述符版本、事件累计计数 | 报告收到≠触控生效 |
| 断开/挂起/恢复 | 触发方、旧/新epoch、清理完成、晚回调丢弃计数 | 唤醒≠会话恢复 |

日志关联键为本地整数`conn_id/epoch/op_id/stream_id`，不是MAC、设备名、原始peerID或长期会话标识。
`mono_ns`仅同一时钟域内排序；另存UTC与单调时钟对齐信息及误差范围，不能跨主机直接相减。

INFO记录阶段迁移；WARN记录可恢复拒绝/超时；ERROR记录失败边界；DEBUG采样记录长度/计数。
媒体日志限速并给出被省略条数，不能由于打印每个包造成假丢包。

## 明确禁止进入普通日志

密钥、私钥、共享秘密、PIN/口令、认证头、完整证书/签名/挑战原文、原始TLV、媒体载荷、
完整RTSP正文、用户曲目/道路名/定位、稳定设备标识。即使是公钥或挑战也不默认记录原文。
不要对低熵秘密做普通哈希后称“脱敏”；使用随机本地材料编号关联，不记录密钥指纹。
异常信息可能带输入内容，禁止直接`str(exception)`或dump整个字典。

## 最小可执行例子

`diagnostic.safe_event`只允许白名单字段：整数计数/本地ID、有限枚举，拒绝多余字段及自由文本。
错误信息固定，不回显被拒绝内容；`reproduce.py --case D10`测试秘密字段、嵌套载荷、换行注入。
它是最小安全日志示例，不是任意第三方日志的自动脱敏器；调用方需保证整数ID确为本地匿名值，
不能把隐私编码成整数绕过类型检查。原始捕获文件不经过该函数，仍需人工审查。

安全分享包只保留工具/构建版本、枚举错误域与值、聚合计数、必要的脱敏帧号引用、
复现步骤和数据保留说明；原始文件哈希用于本地完整性，不自动上传原始文件。
