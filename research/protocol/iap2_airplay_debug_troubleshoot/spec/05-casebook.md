# 案例库：可执行夹具与待台架场景分开

所有D编号均为**SYNTHETIC**：已知注入原因只在夹具内成立，不能把同症状现场问题自动判为同原因。
在仓库根运行：

```powershell
python -B research/protocol/iap2_airplay_debug_troubleshoot/reference-impl/reproduce.py --case D01
```

替换D编号可逐例运行；ALL执行全部。只使用合成数据，无网络动作，失败后恢复原输入做对照。
表内“根因”均限定为注入项；真实案例编号使用T前缀，目前无已证现场根因。

## 已执行的10个本地案例

| ID / 现象 | 最后成功→首次失败 | 证据与注入根因 | 最小复现与预期 | 处置/排除 |
|---|---|---|---|---|
| D01 iAP2帧被拒绝 | 完整原始帧→头校验 | 固定ACK末字节5d变5c；E-LINK | 解析正确字面量、改一位、再截断一字节；坏校验/截断拒绝，原帧仍通过 | 检查重组、宽度、边界；不跳过校验，不自动改成16位试通 |
| D02 导航参数解析后无业务 | 消息结构→typed空值校验 | 总长4空标记变5；E-GATE | 两条0x5200均可结构解码，仅空标记版本通过typed检查 | 不将“解码成功”当语义成功；本测试不执行原生handler/平台调用 |
| D03 响应到达仍在等待 | RTSP完整包→CSeq关联 | 期望8而响应7；E-RTSP | 正确关联、错误关联、重复CSeq头三种输入 | 查连接/epoch/请求表；不将该响应归到最近请求 |
| D04 控制请求似乎卡住 | 头已收全→正文未收全 | 声明4B仅给2B | 补齐后通过，追加下一条数据仍保留剩余；负长度拒绝；chunked明确不支持 | 先完成TCP重组；不能用一次recv长度判对端坏包；此工具不是chunk解析器 |
| D05 验签失败/可能黑屏 | 候选加密基线→认证拒绝 | 分别改tag、改非零AAD；E-SCREEN | 正确输入可打开；两个不同改动均返回None；恢复基线通过 | 同一错误不能证明密钥错；禁止默认零AAD/明文回退；不是Apple库互通向量 |
| D06 音频包能抓到但不能解析 | 标准RTP基本头→CSRC边界 | CC改2但没有8B CSRC | 正常包payload偏移12；坏包SHORT_CSRC；另验证M的8B AAD及切片authenticated=False | 网络RTP、内部M/I坐标分开；本夹具没有解码器，也不能证明“无声音”的现场根因 |
| D07 重连/恢复后错误放行 | 链路就绪→业务门拒绝 | 缺认证门、旧epoch、RESUME无READY | 旧票据拒绝；新票据三门通过才ACTIVE；恢复后仍暂停业务 | 防止旧异步完成回调；模型不执行认证，不自行发0x5000 |
| D08 看不到媒体包 | 已知端点→过滤器构造 | 假设固定7000/6000范围会漏本夹具7123/49152/51000/51001 | 生成精确BPF/显示表达式，检查IPv6与非法端口/注入串 | 仅字符串生成测试，非BPF编译或实际捕获；现场先验证工具与接口 |
| D09 SETUP返回错误 | 完整响应→状态类别 | 合成461与500响应 | CSeq匹配但分别保留4xx/5xx；不生成OSStatus或root_cause | 核对协商与请求，不由461推出具体缺字段，不由500断言车机bug |
| D10 日志泄密/注入 | 结构化事件→白名单拒绝 | 加secret字段/嵌套对象/换行自由文本 | 固定拒绝消息不回显输入；安全整数与枚举仍可记录 | 普通日志不能dump异常/包；该函数不脱敏原始pcap |
