# runtime — 运行时证据

本目录只放**佐证**，不放结论。每份素材都必须能说明：采集环境、构建、能证什么、不能证什么。

| `23G90-bt-classic-2026-10-16.md` | 同一次采集的人工时间线 | 20 步时序，两条连接（`hdr[7]=0x02` BT、`0x03` AirPlay） |

## 这份抓包与本阶段的关系

**它不含本阶段的任何一条消息。**

- 出现过的消息：`0x1D00/0x1D01/0x1D02`（识别）、`0xAA00/0xAA01/0xAA02/0xAA03/0xAA05/0xAA06`（认证）、
  `0x5702/0x5703`（Wi‑Fi Sharing）、`0x4E0D/0x4E0E`（蓝牙连接状态）；
- **没有**出现：`0x68xx`（HID）、`0x50xx`（NowPlaying）、`0x52xx`/`0x0Dxx`（导航）、`0x54xx`（辅助触控）、
  以及任何挂起/恢复包。

因此本阶段所有"参数结构、字段语义"的结论都只有**固件侧**证据（见 `analysis/`），
没有第二条独立来源；任何"线上格式已确认"的说法都超出证据范围。
