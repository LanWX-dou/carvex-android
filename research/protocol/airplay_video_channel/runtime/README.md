## 使用规则

1. 本目录**不能**用来确认 24A446 的常量（构建不同）；
2. 若引用 23G90 的任何日志，必须标 `[23G90]` 并写清"不同构建、仅旁证"；
3. 新增真实抓包时，放在 `runtime/` 下并在此登记：来源设备、构建、抓取方式、时间、文件哈希；
4. 本目录生成清单会收录目录内文件；外置大抓包须在此登记独立哈希及可访问位置，不得假定verify已验证未纳入的外部文件。

## 抓包建议（用于闭合 OPEN-VID-13 等）

- 有线：USB 侧抓 AirPlay 数据流；
- 无线：Wi-Fi 侧抓 TCP/UDP（屏幕流端口来自 SETUP 响应）；
- 至少包含：首帧、若干 P 帧、一次 `forceKeyFrame` 后的帧、一次清屏。

抓到后优先验证：

1. 记录头 128 字节与 `R-2.1`–`R-2.11` 是否一致；
2. 在正确认证解密及去除已证封装后检查NAL/参数集，不直接从密文前缀判断Annex-B或AVCC；
3. 逐段核明文/密文/附加输出长度及状态推进，长度差不能单独证明全部差值都是tag。
