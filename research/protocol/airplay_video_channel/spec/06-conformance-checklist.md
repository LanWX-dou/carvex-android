# 06 一致性清单

> 按已证范围验收；静态、合成、真实profile测试分别报告。OPEN项不能借自写检查通过变成已证；下列条件不是官方认证规范。

## 06.1 格式与记录

| 条款 | 判据 |
|---|---|
| `R-0.5`、`R-2.1` | 抓到的每条记录，头恰好 128 字节，且头后紧跟载荷 |
| `R-2.2` | 按已绑定profile核对头N等于最终body长度及E边界，不得简单填明文长度 |
| `R-2.3`、`R-2.4` | 类型只有 0/1 被本实现产生；未知类型不得猜测其状态影响后盲目跳过 |
| `R-2.5` | `+5` 只有 bit7/bit4 可能非 0 |
| `R-2.7` | 间隔最多16项、ticks转换后≥65536ms为0xffff，含4096/65535/65536边界和未填0测试 |
| `R-2.8`、`R-2.9` | 配置记录 `+4=1`、`+7=1`、`+6` 基值 `0x12` 且条件位正确、10个float落+10/14/20/24/28/2c/30/34/38/3c，+18..1f留空 |
| `R-2.11` | 全部整数小端 |

## 06.2 加密

| 条款 | 判据 |
|---|---|
| `R-3.1` | 头与载荷独立传参；单次调用包含两者，可选尾段另调用一次 |
| `R-3.2` | 仅离线验证NULL上下文no-op，联网建键失败不得自动退回明文 |
| `R-3.3` | 记录拼装成功计数加1，另有清零路径；不能当nonce或送达确认 |
| `R-3.7` | 未绑定profile/nonce/附加输出的实现不宣称密码兼容；不是让联网端遍历未知参数 |

## 06.3 建流与载荷

| 条款 | 判据 |
|---|---|
| `R-1.1` | 无display入参分支默认为110；主副屏语义另核 |
| `R-1.3`、`R-1.4` | 区分内部字典与线上字段，按所选profile验证必需项，不把全部内部键强制定为必填 |
| `R-1.5` | 校验流身份与返回参数；当前类型分派不构成固件相等检查证据 |
| `R-1.6` | 连接方向为"客户端主动连"（抓包可见 SYN 方向） |
| `R-4.1` | 编码输出与目标profile封装对齐；NAL转换职责仍需闭合 |
| `R-4.3`、`R-4.4` | 记录实际profile的协商/参数集与模式变化行为，不能仅从接口名推出必重启 |
| `R-4.7` | bit7按APInterestingFrame，bit4按首个合法布尔NotSync反相；[false,true]与[true,false]不同，数字0/1不冒充布尔；另验NAL随机访问帧 |

## 06.4 时序与恢复

| 条款 | 判据 |
|---|---|
| `R-5.1` | 同批内配置记录在帧之前 |
| `R-5.3` | 分别核字段来源和时钟单位；不能对所有字段要求相同单调规则 |
| `R-5.5` | 静态追forceKeyFrame到编码器生效门；受控运行另记录请求至随机访问帧延迟，不凭单次样本设通用N |
| `R-5.6` | 记录清屏实际行为，解码参考重置条件尚待核 |
| `R-5.7` | 挂起/恢复/断开/致命错误走不同分支（可用注入故障验证） |
| `R-5.8` | 区分临时背压、断开与密码错误；避免将已修改buffer重复加密 |
