# 07 · 一致性清单

设备侧实现自检项。字段与解析项可离线检查；profile、加密切换和身份校验仍需独立证据，不能仅凭回环测试判定。

| # | 检查 | 通过条件 | 依据 |
|---|---|---|---|
| C-1 | 请求行 | `方法 SP URL SP RTSP/1.0 CRLF`，URL 与类型表一致 | `R-4.1` |
| C-2 | `CSeq` | 单调、先取后增、响应按 `CSeq` 匹配 | `R-1.4`、`R-1.5` |
| C-3 | `Content-Length` | 有 body 必有、十进制、与实际字节一致 | `R-4.4` |
| C-4 | 头部上限 | 头部区 ≤8 KiB | `R-4.7` |
| C-5 | Pair-Setup TLV | M1 基础字段 `0`/`6`，不借用 Verify 公钥；SRP M3 含 `3`/`4`；M5 内层含 `1`/`3`/`10`(64B) | `R-2.2`、`R-2.5` |
| C-6 | Pair-Verify | M1公钥32B；区分ECDH/Encrypt标签；常规M2按peer公钥/ID/local公钥验签；恢复ID不当作密钥 | `R-2.8`、`R-2.9`、`R-2.10`、`R-2.15` |
| C-7 | 加密切换 | 只有在加密起始边界已由 profile/抓包确定且 Verify/密钥条件满足后才切换；读写密钥不同 | `R-3.1`、`R-3.3` |
| C-8 | 上下文隔离 | 控制/事件/数据流密钥不混用 | `R-3.4` |
| C-9 | 未知类型 | 不发包、返回错误 | `R-4.9` |
| C-10 | chunked | 能解析 chunk，且不把长度行当正文 | `R-4.11` |
| C-11 | 失败清理 | 无效身份/记录不得用于业务；清理、断开与重试按失败类型和已核 profile，未知保持 OPEN | `R-2.12`、`R-3.8` |
| C-12 | 日志 | 不含密钥/nonce/明文 TLV | `R-2.13` |
| C-13 | 控制记录 | LE16长度作AAD，pad16/LE64认证编排一致；读写nonce独立；部分写不重加密；未验签明文不发布 | `R-3.6`、`R-3.7`、`R-3.8` |
| C-14 | 角色方向 | 核实本地read/write对应的上游标签与角色；不能用名称猜 | `R-3.10` |

未通过项不得声明"可连接车机"。
