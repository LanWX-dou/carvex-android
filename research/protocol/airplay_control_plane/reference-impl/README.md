# reference-impl · 参考实现

只放**协议编解码**，不放任何密钥材料、不放平台 API。

| 文件 | 内容 | 依据 |
|---|---|---|
| `rtsp.py` | RTSP/1.0 请求编码、响应解码、按 `Content-Length` 或 `chunked` 切正文 | `A01.2`、`A01.7`、`A01.8` |
| `tlv8.py` | TLV8 编解码（`type(1) len(1) value`，255 字节以上分片） | `A02.1` |
| `record_layout.py` | 认证输入、记录拆装和 nonce 进位的结构模型；不执行 AEAD | `A13.1`、`A13.2`、`A13.5` |

未提供：完整配对状态机、密钥派生或可用的 AEAD 记录层。基本字节布局已静态确认，
但角色/HKDF 方向、切换时刻、签名及实际互通仍依赖 `OPEN-AP-19`/`22`/`23`/`40` 等证据。
`record_layout.py` 不验证 tag；能拆装记录不等于可以安全接收明文或连接车机。
