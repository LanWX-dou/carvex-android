# analysis/A — 结论登记表

本表是 spec 与 analysis 之间的**唯一编号桥**：每条 `R-x.y` 的"依据"行只允许引用本表里的 `A` 编号；每个 `A` 编号必须指向一个存在的 analysis 文件与章节。

规则：

- 一个 `A` 编号对应**一条可判定的事实**，不是一段叙述。
- 强度三档：`已确认`（指令级 + 反例检查）、`部分确认`（结构/机制有据，字段或分支未取证）、`OPEN`（未取证，正文另有 `OPEN-SES-n`）。
- 引用汇编时给出**指令地址**；引用表时给出**表地址**。
