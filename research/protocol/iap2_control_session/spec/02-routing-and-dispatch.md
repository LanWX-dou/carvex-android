# spec/02 — 会话号与数据面路由

## 2.1 会话号就是链路头的第 8 字节

`R-2.1`（MUST / CONFIRMED）**接收**方向：链路头第 8 字节（`hdr[7]`，0 基）即会话号。它被直接用作会话表的查找键，与表项 `[0]` 比较；命中则把该表项交给分发器。

```
hdr[7] → 遍历 link+0x1b8，比较项[0]（步长 4、项数次字节）→ 命中项
```

匹配规则是"取**最后**一个相等的项"（不是第一个）。实现若保证会话号唯一，两种规则等价；若不保证，必须照固件的"后者覆盖"语义。

依据：`A02.2`。

`R-2.2`（MUST / CONFIRMED）**发送**方向：同一字节在组包时被写入。会话号不是每包参数，而是包头字段。

依据：`A02.4`。

`R-2.3`（MUST / CONFIRMED）`hdr[7]` 之前没有会话号的第二层映射（无表、无查表函数介入）。链路层只做"搬运"，不做"会话识别"。

依据：`A02.2`、`A02.4`。

## 2.2 查不到就丢

`R-2.4`（MUST / CONFIRMED）表项数为 0 或没有匹配项时，该包的数据**不投递**：既不查消息处理器，也不产生任何默认处理。允许记一条日志，但不得赋默认会话。

依据：`A02.3`。

## 2.3 分发：按表项类型

`R-2.5`（MUST / CONFIRMED）分发键是表项 `[1]`（数据面类型），映射固定：

| 类型 | 处理 |
|---|---|
| 0 | 控制通道解析器（`R-3.1` 起） |
| 1 | 文件传输数据面 |
| 2 | 外部配件（EA）数据面，见 `R-2.7` |
| 4 | 会话日志数据面 |
| 其它（含 3） | 返回 0，**静默丢弃** |

实现必须让未知类型走"丢弃 + 返回 0"，不得回落到类型 0。

依据：`A02.5`、`A02.8`。

`R-2.6`（MUST / CONFIRMED）分发只依据类型，不依据版本；版本只被控制会话启动用来选安全流程（`R-4.4`）。

依据：`A02.5`、`A05.3`。

## 2.4 外部配件面的子会话号

`R-2.7`（MUST / CONFIRMED）类型 2 的载荷前 2 字节是**子会话号（大端）**，其余字节才是数据（长度 = 载荷长 − 2）：

| 载荷长度 | 行为 |
|---|---|
| < 2 | 丢弃，返回 0 |
| == 2 | **合法空包**：记日志后返回 1，不构造数据对象 |
| > 2 | 以 `子会话号` 与 `数据` 调用平台回调，返回其结果 |

"空 EA 包是合法事件"必须实现；把 `len == 2` 当错误处理会与固件行为不一致。

依据：`A02.6`。

## 2.5 两个查询方向

`R-2.8`（MUST / CONFIRMED）会话表被两个方向查询，实现必须都提供：

| 查询 | 键 | 结果 | 用途 |
|---|---|---|---|
| 按会话号 | 项 `[0]` | 表项指针 | 接收时分发 |
| 按类型 | 项 `[1]` | 项 `[0]`（会话号，8 位） | 发送时选会话 |

两个查询都是线性扫描，都没有"未找到"的错误码——返回 0 即未找到。实现必须把"0"当未找到，而不是当合法会话号。

依据：`A02.7`。

## 2.6 未决

`R-2.9`（未定义 / OPEN）类型 3 有发送队列槽但没有分发分支，其用途未定。实现必须保留该槽位（以免类型编号错位），但可拒绝注册类型 3。

依据：`A02.8`。

`R-2.10`（MUST / CONFIRMED）**类型编号可以硬编码**，会话号不行。类型有四处独立证据且互相一致：

| 类型 | 收侧分发 | 发侧查表常量 |
|---|---|---|
| 0 | 控制通道解析器 | `iAP2MsgSendCtlDataWithSentCallback` 传 0 |
| 1 | 文件传输数据面 | 文件传输创建/接收、NowPlaying 封面与播放队列、App 图标、文件传输 `getVersion` 全传 1 |
| 2 | 外部配件数据面 | 传变量（从会话对象读），无立即数 |
| 4 | 会话日志数据面 | `sessionLog_sendOutgoingMessage` 传 4 |

类型 1 的业务面比"文件传输"宽：任何"搬一堆字节"的业务（封面图、播放队列、App 图标）都挂它。实现方必须把类型 1 当**通用数据传输面**，而不是只给文件名/数据块用。

依据：`A02.11`、`A02.12`、`A02.5`。
