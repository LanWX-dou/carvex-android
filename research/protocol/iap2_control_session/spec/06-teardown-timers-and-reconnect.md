# spec/06 — 拆除、定时器与重连

## 6.1 拆除释放什么

`R-6.1`（MUST / CONFIRMED）控制会话拆除时必须做四件事：

1. 注销外部配件（以 endpoint 的配件指针为参数）；
2. 标记 endpoint 未初始化；
3. 销毁全部特性；
4. **释放并清零控制缓冲**（`R-4.1` 分配的 65535 字节）。

依据：`A12.1`、`A12.2`、`A12.3`。

`R-6.2`（MUST / CONFIRMED）拆除**不撤销**全局消息处理器字典。处理器是进程级资源，断连后仍可被查找。

依据：`A12.3`、`A01.6`。

`R-6.3`（MUST / CONFIRMED）拆除**不释放** endpoint 与链路对象；它们属于更晚的销毁路径。

依据：`A12.6`。

`R-6.4`（SHOULD / INFERRED）某些传输类型与"无线 CarPlay 已识别"两种情形下，部分清理动作会切到异步工作队列执行，与缓冲释放之间**没有看到显式同步**。实现若采用异步清理，必须自行保证"释放缓冲"不在异步任务仍在引用它时发生。

依据：`A12.4`。

## 6.2 定时器

`R-6.5`（MUST / CONFIRMED）**会话层没有定时器**：初始化、启动、拆除三步都不创建定时器，也没有会话级心跳与保活。链路断开由链路层通知（`R-5.11`），不靠会话层超时判定。

依据：`A11.3`、`A09.4`。

`R-6.6`（MUST / CONFIRMED）全链路只有一个定时器对象，句柄为 `0xff` 时表示空闲；收包路径可能启动一个"延迟确认"类定时器，其超时参数来自链路对象的固定字段。该定时器**不区分会话**。

依据：`A11.1`、`A11.2`。

`R-6.7`（MUST / CONFIRMED）链路层默认的发送参数为 `{version=1, maxRetrans=1, maxCumAck=30}`，另有 `0xFFFF`、`1000`、`10` 三个定值字段。会话层不得修改这些字段。

依据：`A11.2`、`A11.5`。

## 6.3 背压

`R-6.8`（MUST / CONFIRMED）每类型一条发送队列，容量 **255** 项、元素 8 字节（`R-1.6`）。这是会话层唯一的资源瓶颈。

依据：`A11.4`。

`R-6.9`（未定义 / OPEN）队列满时的行为未取证。固件的入队路径只处理"找不到会话"，没有容量判断。实现必须在队列满时返回明确错误。

依据：`A11.4`。

## 6.4 重连

`R-6.10`（MUST / CONFIRMED）链路层在**五处**复位时把会话表清成"0 项"：新建链路、重置发送、附着、发送 RST、分离。因此**每次链路复位后会话表都为空**，会话必须重新登记。

依据：`A12.5`。

`R-6.11`（MUST / CONFIRMED）重连的会话层行为是"清理 → 重新初始化"：缓冲重新分配、特性重新创建、处理器注册被幂等标志挡掉。**不得**期望会话状态跨连接保留。

依据：`A12.1`、`A06.2`、`A09.3`。

`R-6.12`（SHOULD / INFERRED）重连清除旧路由，按新一轮 SYN 协商登记并在连接完成时启用（`R-1.10`、`A02.15`）；不得沿用旧号或自行任意选号。异常重连的全部工作块复位分支仍属 `OPEN-SES-27`。

依据：`A01.8`、`A12.5`。

## 6.5 未决

`R-6.13`（未定义 / OPEN）解析器缓冲（65567 字节）、链路对象与 endpoint 的释放路径未取证。实现必须自行规定这三者的释放时机并写入文档。

依据：`A12.6`。
