## 入库模板

新抓包入库时，把下面这段填好追加到"已入库抓包"一节，并把文件放进本目录：

```text
文件名      :
大小        :
SHA256      :
抓取拓扑    : 手机(型号/系统) ↔ AP(型号) ↔ 车机(型号/固件)
会话类型    : 无线 CarPlay / 有线 / AirPlay 到 Mac
覆盖        : 音频 / 视频 / 双路；时长
PT 分布     : 0x60=n1, 0x61=n2, ...
元素统计    : 每包元素数分布（1/2/3/4…）
解析命令    : python3 ../../reference-impl/rtp_parser.py（或解析脚本名）
结论/关闭项 :
```
