| `A08.1` | 当+0x6b0非零时，用环槽所存序列+1与收到序列比较；不等进入不连续日志分支，不独立证明网络丢包 | `CONFIRMED` |

## 8.2 丢包判定（`A08.1`、`A08.2`、`A08.4`）

`APSRTPPacketHandlerReadNewMessage` 尾部（`0x2519c0e00`–`0x2519c0e40`）：

```asm
0x2519c0e00: add  w8, w8, w9
0x2519c0e04: sub  w8, w8, #1
0x2519c0e08: ldr  w9, [x19, #0x6a8]      ; 容量
0x2519c0e0c: udiv w10, w8, w9
0x2519c0e10: msub w21, w10, w9, w8       ; index = f(counter) mod 容量
0x2519c0e14: add  x0, x19, #0x680        ; 队列
0x2519c0e18: mov  x1, x21
0x2519c0e1c: bl   #0x2519c1a64           ; 取该索引记录
0x2519c0e20: ldr  x8, [x19, #0x6a0]      ; 序列号数组
0x2519c0e24: ldr  w8, [x8, w21, uxtw #2] ; last_seq[index]
0x2519c0e28: add  w9, w8, #1             ; expected = last + 1
0x2519c0e2c: ldr  x8, [x19, #0xa8]       ; 收包缓冲
0x2519c0e30: ldrh w8, [x8, #2]           ; 收到的 seq（大端字节）
0x2519c0e34: rev  w10, w8
0x2519c0e38: and  w21, w9, #0xffff       ; expected & 0xffff
0x2519c0e3c: cmp  w21, w10, lsr #16      ; 与收到的 seq 比较
0x2519c0e40: b.eq #0x2519c0eb0           ; 相等 → 正常路径
```

由此确定（可实现）：

1. 比较使用内部环槽索引的序列记录（32位存，低16位比较）；不能仅凭数组称它为“每流最后序列号”；
2. 期望值 = `last + 1`，按 16 位回绕（`and #0xffff`）；
3. 收到的序列号按大端 16 位解释（`ldrh` + `rev` + `lsr #16`）；
4. 不等触发可选日志后返回既有状态；可能为丢包/乱序/重复等，不能直接作为已丢包数量（`A10.4`）。

`obj+0x6a0`（数组）、`obj+0x6a8`（容量）、`obj+0x680`（队列）三个字段与 `analysis/00` 记录的对象布局一致。

## 8.3 丢包分支不重传（`A08.3`）

```asm
0x2519c0e44: ldr w9, [x23, #0x608]   ; gLogCategory 的日志级别
0x2519c0e48: cmp w9, #0x1e
0x2519c0e4c: b.gt #0x2519c0eb0
0x2519c0e50: cmn w9, #1
0x2519c0e54: b.eq #0x2519c0e9c
```

不相等时只走日志级别判断，函数内**没有**构造重传请求的写包动作（没有向发送队列写入控制包的调用）。因此：

- “检测到序列不连续”= `CONFIRMED`；不是已证网络丢包；
- "会请求重传"= **无证据**（`OPEN-RTP-12`）。

## 8.4 统计与控速：无证据（`A08.5`–`A08.7`）

本轮**没有**产出下列任何一条的条款，原因是没有任何指令或运行期证据：

| 主题 | 现状 |
|---|---|
| 丢包率/乱序率/重复率/迟到率 | 无计数器证据；`jitterBuffer_*` 族里也没有统计字段的读写 |
| 统计窗口与上报方式 | 无证据 |
| 发送节奏（pacing） | 只见合并数 `obj+0x1c` 与缓冲容量 1460 两条约束，没有时间轴/令牌桶/背压证据 |
| 断流、时钟跳变、车机差异 | 无证据 |

`spec/05`、`spec/06` 已存在，但只登记未知与实现策略边界，不提供已核统计/控速算法。
