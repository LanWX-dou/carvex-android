# spec/00 — 范围、术语与条款约定

## 0.1 本规范的范围

本规范描述 **iAP2 链路建立阶段**的平台无关行为，来源是 iPhone 17 Pro（`iPhone18,1`）iOS 27.0.1（build `24A446`）中 `accessoryd` 的 ARM64 机器码。覆盖：

1. 传输绑定与运行循环驱动；
2. 帧格式、长度与校验；
3. SYN 协商（参数、线格式、合法性、协商结论）；
4. 序号、确认与重传（已确认部分）；
5. 链路状态机（8 状态、事件表）；
6. 识别 / 认证 / 会话启动边界（消息级）；
7. 异常、拆除与清理；
8. 传统 iAP 控制帧（Detect / DetectNACK / RequestIdentify）。

**不覆盖**：USB 传输、消息层各消息的载荷结构、认证密码学细节、会话内业务消息。

## 0.2 条款状态

**适用性更正（2026-10-26）**：这是指定固件的逆向实现参考，不是 Apple 官方 CarPlay/MFi 规范。`CONFIRMED` 表示限定范围内有证据，不表示所有车机必须如此。对象字节大小/指针偏移、内部队列数、状态编号和注册规模只描述 iOS 实现，不是独立客户端必须复制的 ABI；实现者可用不同结构，只要已验证的线上行为一致。下文历史 MUST 对这些内部结构不得解释为跨平台硬要求。`OPEN` 表示实现缺口；配置开关本身不能补齐未知协议或使实现安全可用。

每条条款带一个状态，实现方**只能**依赖 `CONFIRMED`：

| 状态 | 含义 | 实现方义务 |
|---|---|---|
| `CONFIRMED` | 固件字节/指令直接证明 | 必须按条款实现 |
| `INFERRED` | 由固件结构或符号推断，未直接证明 | 可参考，但必须自行验证 |
| `OPEN` | 未证明 | **不得**依赖；行为须可配置 |

`OPEN` 条款登记到 `STATUS.md`。配置点只用于受控验证，不能把未知协议变成任意默认值；不支持的 profile 应显式报错。

本规范用三个规范性动词（RFC 2119 风格）与上表一一对应：

| 动词 | 状态 | 实现义务 |
|---|---|---|
| **MUST** | `CONFIRMED` | 必须一致 |
| **SHOULD** | `INFERRED` | 应一致，但须自行验证 |
| **未定义** | `OPEN` | 待补证；受控试验记录配置，未验证的能力显式不支持 |

条款书写形式固定为 `` `R-x.y`（MUST / CONFIRMED）``，便于机器校验（`verify.py` C6 检查每条规则都带动词）。

## 0.3 术语

| 术语 | 含义 |
|---|---|
| 链路（link） | 一条 iAP2 连接的对象，含 FSM、发送队列、序列状态 |
| 运行循环（runloop） | 驱动链路的事件泵，持有 link 与 transport |
| 帧（frame） | 线上字节：头 + 头校验 + 载荷 + 载荷校验 |
| 载荷（payload） | 消息层数据 |
| SYN 参数结构 | 50 字节；`link+0x168` 为工作块，`link+0x19a` 为提交后生效块（固件内部布局） |
| 传统帧 | 以 `FF 55` 开头的 iAP 控制帧（Detect 等） |
| 方向 | `A→D`（附件发给设备）或 `D→A` |

## 0.4 编号与引用

- 条款：`R-<章>.<序>`，例如 `R-2.4`。
- 分析结论：`A<文件>.<序>`，例如 `A03.6`，位于 `analysis/`。
- 函数：写作 `名字` + 地址，地址为构建 `24A446` 的虚拟地址（`__TEXT` 起点 `0x100000000`）。
- 所有地址、常量都以 `source/asm/accessoryd/` 的汇编为准；`verify.py` 校验地址落在镜像窗口内。

## 0.5 与实现相关的硬约束（汇总）

| 约束 | 条款 |
|---|---|
| 头部固定 8 字节 + 校验 | `R-2.1` |
| 长度字段为**整帧长度**、大端 | `R-2.2` |
| 校验范围：iAP2 含 `FF 5A`，传统帧不含 `FF 55` | `R-2.5` |
| 创建默认 8 位校验；字段值与算法编号不能混用 | `R-2.8` |
| 序号 8 位、模 256 | `R-4.1` |
| SYN 参数结构 6 个必需字段 | `R-3.1` |
| 状态机 8 状态、链式迁移 | `R-5.1`、`R-5.5` |
| 事件表"命中即用、无副作用" | `R-5.6` |
