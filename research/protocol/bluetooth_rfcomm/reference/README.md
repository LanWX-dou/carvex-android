# reference/ —— 外部参考（不参与证据链）

## 1. 规则

1. 本目录只放**外部资料**：规范文本、第三方实现说明、术语表等。
2. 本目录内容**不得**作为本套文档任何结论的依据；所有结论必须回到 `source/` + `analysis/`。
3. 引用外部资料时，只能用于**命名对齐**（例如"这个词在规范里叫什么"），不能用于"所以固件一定是这样"。

## 2. 术语对齐（非证据）

| 本套文档用词 | 常见规范用词 | 说明 |
|---|---|---|
| 复用器 / 会话 | multiplexer / session | 一条 L2CAP 通道上的 RFCOMM 实例 |
| DLCI 0 | multiplexer control channel | 控制通道 |
| 数据链路 | DLCI | 0 以外的通道 |
| 信息字段 | information field | 地址/控制/长度之后、FCS 之前 |
| 最大帧长 N1 | N1 | 单个信息字段上限 |
| 信用 | credits | 基于信用的流控额度 |
| 方向位 | — | 本套文档自造，指 `session[0xc]`，用于 DLCI 与 C/R 计算 |

## 3. 与外部规范的关系说明

本套文档在以下三处**与常见实现习惯不同**，属于固件实测行为，不是笔误：

| 编号 | 差异 | 位置 |
|---|---|---|
| F-001 | 收到 DISC 回 **DM** 而非 UA | `analysis/06` C2、`spec/06` R-6.6 |
| F-002 | 上层可见的 "MTU" 实为 N1 | `analysis/05` C9、`spec/05` R-5.23 |
| F-003 | 复用器命令长度不符直接拆链路 | `analysis/06` C4、`spec/04` R-4.25 |

若你的实现按常见习惯处理这三处，将无法与 iPhone 互通。详见 `analysis/08` 第 4 节。
