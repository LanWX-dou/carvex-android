# 07 一致性检查清单

本清单用于判定一个实现是否符合本规范。每一项给出**判据**与**验证方法**。

## 7.1 规范性测试向量（FCS 与帧编码）

FCS 算法（必须逐字节一致）：

```
table 为 256 字节 CRC-8 表，由"反射形式、多项式 0xE0"生成
（等价于多项式 x^8+x^2+x+1，LSB-first 计算）
表首 8 字节必须为：00 91 E3 72 07 96 E4 75
fcs = 0xFF; for each byte b: fcs = table[b XOR fcs]; fcs = fcs XOR 0xFF
```

FCS 覆盖范围见 R-4.4：UIH 仅前 2 字节，以下无信息控制帧前 3 字节。改变 UIH 载荷不改变 FCS，不能用载荷翻转验证 FCS 拒收。

**TV-1** 下列帧的完整字节必须逐字节一致：

| 编号 | 描述 | 完整字节（十六进制） |
|---|---|---|
| TV-1.1 | SABM，复用器发起方 D=1，DLCI 0，P=1 | `03 3F 01 1C` |
| TV-1.2 | DISC，D=1，DLCI 0，P=1 | `03 53 01 FD` |
| TV-1.3 | UA，复用器响应方 D=0，DLCI 0，F=1，无信息 | `03 73 01 D7` |
| TV-1.4 | DM，D=0，DLCI 0，F=1，无信息 | `03 1F 01 36` |
| TV-1.5 | UIH，DLCI 2，3 字节信息 `01 02 03` | `09 EF 07 01 02 03 40` |
| TV-1.6 | UIH，DLCI 2，128 字节信息（`00..7F`） | `09 EF 00 01` + `00..7F` + `40`（长度字段为双字节 `00 01`，FCS = `40`） |

说明：TV-1.5 中长度字节 `0x07` 表示长度 3（`3<<1|1`）；TV-1.6 中 `0x00 0x01` 表示长度 128（`128<<1 = 0x0100`）。

**TV-2** 反向验证：把 TV-1.1 的最后一个字节改成任意其他值，接收方必须静默丢弃（无响应、无状态变化）。

## 7.2 发现与识别（第 01 章）

| 编号 | 判据 | 验证方法 |
|---|---|---|
| CF-01 | EIR 总长 ≤ 240 | 解析 EIR，累加所有 `1+length` |
| CF-02 | 每个 AD 结构 `length == 1 + data 长度` | 逐结构校验 |
| CF-03 | 存在 `[len][0x09][name]` | 查找 type=0x09 |
| CF-04 | 五个 128-bit UUID 逐字节正确且为小端 | 与 01.3.1 表比对**字节序列**（不是 UUID 文本） |
| CF-05 | 关闭某能力后对应 UUID 消失 | 逐个关闭能力重测 |
| CF-06 | 同时开启经典 + LE 能力仍 ≤ 240 | 全能力开启 |
| CF-07 | UUID→名称映射覆盖 13 项 | 用 13 个 UUID 逐个查询 |
| CF-08 | 经典 EIR 中的 LE CarPlay 标识被忽略 | 注入该标识，确认不改变 LE 能力状态 |

## 7.3 服务注册与 SDP 服务端（第 02 章）

| 编号 | 判据 | 验证方法 |
|---|---|---|
| CF-09 | 注册输入格式为 `[count:2][attrID:2][DE]...` | 用已知属性列表注册并回读 |
| CF-10 | `0x0001` 支持 2/4/16 字节 UUID | 三种长度各注册一次 |
| CF-11 | 重复注册返回"已存在" | 连续注册两次 |
| CF-12 | 记录句柄唯一且稳定 | 注册 N 条，多次查询句柄不变 |
| CF-13 | 通道号 = DLCI>>1，且 0–30 有效 | 注册 31 个通道并检查越界拒绝 |
| CF-14 | 返回条数 = min(请求, (MTU-12)/4) | 用大/小 MTU 各测一次 |
| CF-15 | 截断时 continuation 非空，续读不重复不遗漏 | 构造 20 条记录 + 小 MTU |
| CF-16 | 所有整数大端，128-bit UUID 大端 | 抓包逐字节比对 |
| CF-17 | 非法 UUID 列表返回错误 PDU | 注入空/畸形搜索模式 |
| CF-18 | 无匹配返回 0 条而不报错 | 搜索不存在的 UUID |
| CF-19 | 属性范围查询返回范围内全部属性 | 用 `0x0000`–`0x0009` 范围 |
| CF-20 | 属性列表截断时不出现半个属性 | 属性值跨边界 |

## 7.4 SDP 客户端（第 03 章）

| 编号 | 判据 | 验证方法 |
|---|---|---|
| CF-21 | 对端不支持 `0x0200` 时降级为全量查询 | 用不支持该属性的模拟服务端 |

## 7.5 链路建立（第 04 章）

| 编号 | 判据 | 验证方法 |
|---|---|---|
| CF-29 | TV-1.1–TV-1.6 全部通过 | 单元测试 |
| CF-30 | DLCI↔通道号双向换算 | 遍历 0–30 |
| CF-31 | 五道 SABM 校验各自可触发丢弃 | 见 R-4.13 的分支判据 |
| CF-32 | 无注册服务 → DM | 对未注册通道发 SABM |
| CF-33 | 状态 6（DISC 等确认）再收 SABM → DM | 重复 SABM |
| CF-34 | 合法 EA/P/F/C/R 的 SABM 地址 ≥ 0xF8 → DM | 注入 `0xF8` 地址帧 |
| CF-35 | DLCI 1 的 SABM → DM | 构造 DLCI 1 |
| CF-36 | 命令帧长度不符 → 链路销毁 | 长度 ±1 |
| CF-37 | `N1 ≤ 信用窗口` 校验生效 | 非法参数连接 |

| CF-39 | C/R 方向与对端一致（互通） | 与不同实现对接 |

## 7.7 生命周期与边界（第 06 章）

| 编号 | 判据 | 验证方法 |
|---|---|---|
| CF-52 | 主动 DISC → UA → 释放 | 端到端 |
| CF-53 | 主动 DISC 无响应 → 超时释放 | 屏蔽对端响应 |
| CF-54 | 被动 DISC → 回 UA → 释放 | 对端发 DISC |
| CF-55 | 重复 DISC 幂等（只回调一次） | 连发 3 次 |
| CF-56 | 复用器 DISC → 断开中 + 定时器 + UA | 对端 DISC DLCI 0 |
| CF-57 | 清理顺序正确（定时器先取消） | 清理期间不触发回调 |
| CF-58 | 最后一个 DLCI 关闭时上报原因码 | 检查上报内容 |
| CF-59 | 链路销毁时全部 DLCI 上报异常 | 注入长度错命令 |
| CF-60 | 重连复用会话（无新 DLCI 0 SABM） | 抓包比对 |
| CF-61 | 旧句柄操作返回"句柄无效" | 会话销毁后用旧句柄 |
| CF-62 | 重连次数上限与退避生效 | 反复断连 |
| CF-63 | 上层能区分两次交付（非拼接） | 两帧不同长度 |
| CF-64 | SDP 中按**逆序**字节匹配 CarPlay 族 UUID 能命中（R-1.8a/b） | 用 `d31fbf50-…` 字节构造搜索模式，对真实设备应返回记录 |
| CF-65 | 只按文本序匹配 CarPlay 族 UUID 时确认**失败**（负向用例） | 同上，用 `ec884348-…` 字节，预期无记录 |
| CF-66 | `0x0004` 缺少 L2CAP PSM 参数时仍能取到通道号（R-3.11a） | 用实测记录 `SEQ[SEQ[0x0100],SEQ[0x0003,ch]]` 回放 |
| CF-67 | 通道号非固定：换一台设备后仍从 SDP 读取而非沿用上次值（R-3.16） | 两台通道号不同的设备交替连接 |
| CF-68 | 未识别命令（如 `0x40`）回 NSC，数据字节 = 原命令 `& 0xFE`（R-4.26/L-13） | 发 `40 03 xx` 观察回帧 `11 03 40` |
| CF-69 | PN 数据区非 8 字节时按非 PN 处理（R-4.28/L-14） | 发 7 字节 / 9 字节 PN 各一次 |
| CF-70 | PN 生效 N1 = min(本地, 对端)，且信用上限 7（R-4.28） | 本地 127 + 对端 200 → 期望 127；对端信用 20 → 期望 4（20 & 7，不是饱和） |
| CF-71 | MSC < 2 字节、RPN < 1 字节时丢弃且**不崩溃**（R-4.31/L-16/L-17） | 各构造 3 个长度异常帧 |
| CF-72 | PN 裸 DLCI 不得猜成地址字段（R-4.29a） | 同时存在 DLCI 2 和 11 时，PN 的 0x0B 必须对应 11，不得对应 2 |
| CF-73 | 会话超时可配置且默认 30（R-4.32） | 改配置项 50 的 16 位值，观察等待时长随之变化；默认值下约 3 s 断链 |
| CF-74 | 超时值 ≥ 0x8000 被拒绝登记（R-4.33） | 配置为 32768，应被拒或回落默认 |
| CF-75 | 默认会话超时为 3.000 s ±10%（R-4.32） | 发出 SABM 后不回 UA，测量到断链的时间 |
| CF-76 | 超时按「100 ms/单位」换算，配置 10 应表现为 1 s（R-4.32） | 配置项 50 设为 10，重复 CF-75 的测量 |
| CF-77 | 断链后 RFCOMM 层不自行重连（R-6.21） | 拔掉配件再上电，观察本层无自动 SABM；重连由上层触发 |
| CF-78 | 重试次数受硬上限约束（R-6.22/6.23） | 让配件持续拒绝连接，统计尝试次数应为 5 次后停止 |
| CF-79 | 未识别复用器命令回 NSC 而非销毁链路（R-6.17/R-4.26） | 发 `0xFF` 命令，应收到 `11 03 FE` 且链路保持 |

## 7.8 必须明确记录的实现选择

以下各处本规范允许实现自选，但**必须**在实现文档中写明，否则视为不可判定：

| 编号 | 选择点 | 影响 |
|---|---|---|
| CH-01 | 会话角色应保存并按 R-4.14 编码（不是自由选择） | 直接决定能否与对端建立链路 |
| CH-02 | 超时定时器单位与缺省值（参考值 30×100 ms） | 断链快慢、重连时机 |
| CH-03 | 超信用接收后是交付还是丢弃 | 上层可观测行为差异 |
| CH-04 | 命令帧长度不符时，销毁链路前是否上报部分数据 | 上层错误处理 |
| CH-05 | 未知命令按 R-4.26 回 NSC | 与未来对端命令的兼容性 |
| CH-06 | 重连退避策略与上限 | 异常场景下的行为 |
| CH-07 | N1 > 2570 时的分块策略 | 吞吐与上层分块假设 |
